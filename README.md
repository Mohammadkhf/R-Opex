# R-Opex

This repository contains the implementation used in the **numerical experiments** of the paper:

> *Regularized Operator Extrapolation Method for Stochastic Hierarchical Variational Inequality Problems.*

The code reproduces the experiments reported in the numerical section of the paper and provides an implementation of the **R-Opex algorithm** for solving stochastic hierarchical variational inequality (HVI) problems.

---


This repository provides:

- An implementation of the **R-Opex algorithm**
- Scripts for reproducing the **numerical experiments**
- Utilities for computing **optimality and feasibility gaps**
- Plotting routines for the results shown in the paper
